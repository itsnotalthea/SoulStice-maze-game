Academic Group Project for Data Structures and Algorithms.

A maze game that uses Depth-First Search with a backtracking algorithm.

## Gameplay

Bring BODY and SOUL together in a maze. Move with the arrow keys or W, A, S, D;
SOUL moves in the opposite direction. Complete a level before its countdown
reaches zero to unlock the next level. The 21 level time limits gradually drop
from 35 seconds to 20 seconds.

The main menu includes an achievements collection and a three-page tutorial.
Achievement and level progress are saved locally using Java Preferences.
